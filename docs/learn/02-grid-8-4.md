# 2. The 8+4 grid

Every spacing and size utility sits on a fixed rhythm (1 step = 4px):

| Scope | Allowed steps | Where |
|---|---|---|
| Layout | `0 2 4 6 8 10 12 16 20 24 28` | blocks, apps, section padding, gaps |
| Controls | layout steps plus `1 3 5 7 14` | `packages/ui` recipes and icons (`h-14` is the Habitus `xl` button) |

No half steps (`p-2.5`), no arbitrary values (`p-[13px]`). Step 28 (112px) is the section spacing measured in Figma.

## How it is enforced

- The rhythm is written once in [`tools/ui8px/allowed.base.json`](../../tools/ui8px/allowed.base.json).
- [`tools/ui8px-policy.ts`](../../tools/ui8px-policy.ts) intersects it with the codegen 2.0 grid and writes [`.ui8px/policy/allowed.json`](../../.ui8px/policy/allowed.json). It fails if a rhythm step is off the 2.0 grid.
- [`tools/ui8px-gate.ts`](../../tools/ui8px-gate.ts) lints every class map. Its blocking count must be 0.
- A reviewed exception goes into [`tools/ui8px/allowed.extra.json`](../../tools/ui8px/allowed.extra.json); it must stay on the grid and use token colors.

The editor rule is [`.cursor/rules/grid-8-4.mdc`](../../.cursor/rules/grid-8-4.mdc). Figma values that are off the grid are snapped, and the deltas are logged in [`.project/backlog/`](../../.project/backlog/README.md).
