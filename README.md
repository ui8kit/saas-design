# saas-design — Figma → site + design system, end to end

A **viability check** for a fully generated front-end pipeline. One local Figma file (`.fig`) becomes:

- **`apps/site`**: a static copy of the Figma landing page, rendered with **Go templ** (exported to plain HTML).
- **`apps/design-svelte`**: a **Svelte 5 / SvelteKit** design-system app with foundations, primitives, components, widgets and every block.
- **`apps/design-react`**: the same design-system app in **React 19** (Vite SSR + static prerender), page for page.
- All three use the **same** tokens, semantic CSS, primitives and blocks, generated by **[@ui8kit/codegen](https://github.com/ui8kit/codegen) 2.0** from one source per layer. Parity tests check that the three runtimes give **identical DOM/ARIA**. The two design apps share their content through `packages/design-docs`, and their prerendered pages are compared DOM for DOM.

Everything between the `.fig` and the deployed apps is a script in this repo or a pinned public tool. `bun run check` fails if any generated file drifts from its source.

> Developers: start with [Quickstart](#quickstart). AI agents: read [AGENTS.md](AGENTS.md) first.

## Pipeline

```mermaid
flowchart LR
  fig[".fig file<br/>(outside the repo)"] -->|"bun run extract<br/>fig2design parse"| figma["fixtures/figma<br/>frames, variables, images"]
  figma -->|"bun run tokens<br/>+ fixtures/tokens/mapping.json"| tokens["shadcn HSL tokens<br/>packages/tokens/theme.css<br/>+ app brand.css"]
  tokens -->|"bun run brand:emit / brand:check"| brandos["brand-os bundle<br/>fixtures/tokens/brand.generated"]
  figma -->|"bun run content"| records["@ui8kit/contract records<br/>fixtures/content/records"]
  records -->|"bun tools/views.ts"| views["view models<br/>fixtures/views/*.json"]
  recipes["codegen 2.0 specs<br/>+ packages/ui/recipes overrides"] -->|"@ui8kit/codegen 2.0 (xgen)"| ui["packages/ui<br/>templ + Svelte 5 + React 19"]
  ui --> adapter["packages/adapter<br/>ui-* classes, @apply only"]
  defs["block DSL<br/>packages/blocks/defs"] -->|"packages/blocks generate"| blocks["packages/blocks<br/>templ + Svelte 5 + React 19"]
  blocks --> adapter
  tokens --> adapter
  views --> site["apps/site<br/>Go templ → static HTML"]
  views --> design["apps/design-svelte<br/>SvelteKit static"]
  views --> designr["apps/design-react<br/>Vite SSR → static"]
  blocks --> site
  blocks --> design
  blocks --> designr
  adapter --> site
  adapter --> design
  adapter --> designr
  site --> check["bun run check<br/>drift, contract, parity, ui8px, lint-apps, builds"]
  design --> check
  designr --> check
  check --> shots["bun run shots / shots:modes<br/>Figma vs site screenshots"]
  shots --> vercel["Vercel<br/>three projects"]
```

Layer details: [docs/architecture.md](docs/architecture.md).

  design-docs/          framework-neutral docs content of the design apps: nav, block data, foundation scales,
                        ds-* stylesheet, foundations CSS generator (output goes into each app: it uses brand colors)

  site/                 Go: views/layout.templ, cmd/export (static export), scripts/build.sh, vercel.json
  design-svelte/        SvelteKit: src/routes, src/lib (frame, Section, Showcase), vercel.json

## Quickstart

### Prerequisites

| Tool | Version | Tested here |
|---|---|---|
| Bun | ≥ 1.2 | 1.4.2 |
| Node.js | ≥ 20 (`npx` for fig2design, ui8px, brand-os, Tailwind CLI) | 20.19.2 |
| Go | ≥ 1.23 (`go.mod`) | 1.27.2 |
| templ | v0.3.1070, pinned through `go run`, nothing to install | — |
| Google Chrome | for screenshots and behaviour tests only (`/usr/bin/google-chrome`, or `CHROME=/path`) | — |

### Install and verify

```bash
git clone https://github.com/ui8kit/saas-design && cd saas-design
bun install
bun run check            # must end with "all checks passed"
```

### Extract a Figma file (optional; the dump is committed)

The `.fig` must live **outside** the repo. `tools/extract.sh` refuses a path inside it, and `*.fig` is git-ignored.

```bash
FIG=/absolute/path/outside/repo/file.fig bun run extract
# runs, from /tmp:  npx -y fig2design@0.1.0 parse "$FIG" --out fixtures/figma --no-config
```

The variable is `FIG`; without it the default is `/workspace/fig-fixtures/saas.fig`. Then regenerate and re-check with the pipeline in [AGENTS.md](AGENTS.md#pipeline-order). For a **different** Figma file, follow [docs/replicate-with-new-figma.md](docs/replicate-with-new-figma.md).

### Run the apps

```bash
# site (Go templ → static HTML in apps/site/public)
bun run site:build                         # = bash apps/site/scripts/build.sh
(cd apps/site && bun run serve)            # npx -y serve@14 public -l 4173 → http://localhost:4173

# design system app (SvelteKit)
(cd apps/design-svelte && bun run dev)            # vite dev → http://localhost:5173
bun run design-svelte:build                       # → apps/design-svelte/build (50 prerendered pages)

# design system app (React 19)
bun run design-react:build                        # → apps/design-react/build (50 prerendered pages)
(cd apps/design-react && bun run preview)         # vite preview of build/
```

### Other runtimes

`@ui8kit/codegen` 2.0 also emits Vue 3, Solid, Twig, Latte and Jinja2. This repo wires templ, Svelte and React. [docs/add-a-runtime.md](docs/add-a-runtime.md) walks through how React was added, as the recipe for the next runtime.

## Use it with an AI agent

The repo is written so that an AI coding agent can repeat the result. Point the agent at the repo and ask in plain words. It should read [AGENTS.md](AGENTS.md) first; the guides it needs are [docs/replicate-with-new-figma.md](docs/replicate-with-new-figma.md) (another design) and [docs/add-a-runtime.md](docs/add-a-runtime.md) (another framework).

Example prompts:

- **You like this design but want React / Next.js:**
  > "I want a restaurant website in this same design, on React. Build it in `apps/resta`."
- **You found another great Figma design:**
  > "Study this repo and build me a site and a design system for this design, on Vue. The `.fig` is at `/path/outside/the/repo/design.fig`."
- **Same design, different content:**
  > "Keep this design, but turn the landing page into a fitness-coach site. Change the copy and images through the fixtures, not the components."
- **Another page in the same system:**
  > "Add a pricing page and a blog index to `apps/site`, reusing the existing blocks."

> **Note: this repo has three runtimes, Go templ (`apps/site`), Svelte 5 (`apps/design-svelte`) and React 19 (`apps/design-react`), kept in parity.** If you don't need both, say so up front, e.g. "I want **React only**" (or "Vue only", "Svelte only"). The agent then drops the other runtimes' outputs, apps and checks instead of keeping them in sync. How each request is interpreted: [AGENTS.md → How to interpret common requests](AGENTS.md#how-to-interpret-common-requests).
